# PyForge

**PyForge** is a fast, lightweight, distraction-free code editor and interactive execution environment **built on Python 3.15**. Designed for beginners building real coding muscle memory and developers who want pure, uninterrupted speed, PyForge eliminates bloated extensions and intrusive autocomplete popups.

---

## Key Features
* **Built on Python 3.15:** Engineered directly on Python 3.15 for modern performance, responsiveness, and native local execution.
* **Zero-Autocomplete, Distraction-Free Coding:** No annoying popups or AI interruptions—write clean Python from scratch and truly master the syntax.
* **Built-In Interactive Terminal Engine:** Runs saved `.py` scripts live using unbuffered streaming (`-u`), complete with a dedicated `>` input bar for seamless `input()` handling.
* **Save-First Workflow:** Automatically enforces saving (`Ctrl + S`) before execution so your projects stay organized and run directly from disk.
* **Interactive First-Launch Guide:** Includes a built-in, 4-step **Welcome Guide** that walks new users through every button, shortcut, and feature on startup.
* **Clean Dark+ Interface:** Sleek, modern dark theme with crisp toolbar controls and essential keyboard shortcuts (`Ctrl + O`, `Ctrl + S`, `F5`).

## How to Run (Windows)
1. **Standalone App (Recommended):** Download `PyForge.exe` from the **Releases** section and double-click to launch. *(Requires Python 3.15 installed on your system to execute your scripts.)*
2. **From Source:** Download the `.py` file and `my complier icon.ico` into the same folder, install Pillow (`pip install pillow`), and run with Python 3.15.
